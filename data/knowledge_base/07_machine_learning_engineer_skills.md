# Machine Learning Engineer Skills

## Core technical skills
Python, SQL, linear algebra, probability and statistics, scikit-learn, PyTorch, and Git.

## Engineering skills
Docker, REST APIs with FastAPI, cloud platforms (AWS or GCP), experiment tracking with MLflow, automated testing, and CI/CD.

## LLM application skills
Prompt engineering, embeddings, vector databases such as FAISS, Retrieval-Augmented Generation, and evaluation of LLM outputs.

## Machine learning engineer vs data scientist
A data scientist focuses on analysis, experiments, and insights. A machine learning engineer focuses on turning models into reliable production systems that are monitored and maintained. An AI engineer specializing in LLM applications builds products on top of pretrained models rather than training them from scratch.

## Soft skills
Clear written communication, the ability to explain model limitations to non-technical people, and working in teams.

## NIT course mapping
MLOps skills are taught in AI-330 MLOps and Deployment, taken in Semester 7.
