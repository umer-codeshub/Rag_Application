# Python for AI

Python is the standard language for AI and machine learning because of its readable syntax and large ecosystem of libraries.

## Recommended version
Python 3.10 or newer.

## Essential libraries
- NumPy: fast numerical arrays.
- pandas: tabular data manipulation.
- Matplotlib and seaborn: visualization.
- scikit-learn: classical machine learning.
- PyTorch: deep learning.
- Hugging Face Transformers and Sentence-Transformers: pretrained language models and embeddings.
- FAISS: efficient similarity search over vectors.

## Tools
Jupyter notebooks, Google Colab (free GPU access), virtual environments (venv), and Git for version control.

## Learning order
First learn core Python (functions, classes, file handling), then NumPy and pandas, then scikit-learn, then PyTorch.

## At NIT
Python is the only programming language used in the AI program. CS-101 Programming Fundamentals, taken in Semester 1, teaches Python from scratch and has no prerequisites. A student who asks which language to learn first should learn Python.
