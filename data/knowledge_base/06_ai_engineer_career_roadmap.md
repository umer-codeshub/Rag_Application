# AI Engineer Career Roadmap

This roadmap assumes about 10 to 15 hours of study per week and takes roughly 15 months.

## Stage 1: Foundations (months 1-3)
Learn Python, NumPy, pandas, and the required math: linear algebra, probability, and basic calculus.

## Stage 2: Machine learning (months 4-6)
Learn scikit-learn, model evaluation, and feature engineering. Complete two projects on tabular data.

## Stage 3: Deep learning (months 7-9)
Learn PyTorch, CNNs, and Transformers. Train models on Google Colab with a free GPU.

## Stage 4: Specialization (months 10-12)
Choose NLP or computer vision. Learn to build LLM applications, including prompt design, embeddings, and Retrieval-Augmented Generation.

## Stage 5: Deployment (months 13-15)
Learn Git, Docker, FastAPI, and cloud deployment. Deploy at least one project publicly.

## Portfolio advice
Build 3 to 4 projects with clear README files and public GitHub repositories. A deployed RAG application is a strong portfolio project because it shows end-to-end engineering.
